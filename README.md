# Riman Maharjan — Developer & Engineering Portfolio

A modern, responsive, high-performance single-page personal portfolio for **Riman Maharjan**, undergraduate student in **Electronics, Communication and Information Engineering** at **Sagarmatha Engineering College (IOE)**, research member at **SRDC**, and full-stack developer.

## ✨ Highlights & Features

- **No Over-the-Top Glow Fluff**: Clean, sleek, high-craftsmanship developer aesthetic (deep slate, crisp borders, high contrast, typography focused).
- **Curved Dotted Walking Path (Education Section)**:
  - An SVG curved dotted path on the left.
  - A character / walker avatar that actively walks along the path as you scroll through the education stages (SEE 2008-2021 -> +2 Science 2021-2023 -> Bachelor in Electronics & Info Eng 2024-Present).
  - Also includes interactive quick-stage selectors.
- **Crazy Interactive Engineering Lab**:
  - **ESP32 Hardware Breadboard Simulator**: Click GPIO 2 to toggle physical onboard LED, GPIO 4 to pulse piezo buzzer (with real Web Audio sound), DHT22 temperature and humidity sliders, virtual 128x64 OLED display, and live serial monitor.
  - **TriCalendar Lunar & BS Algorithm Sandbox**: Live interactive preview of Riman's Java backend that calculates Bikram Sambat (BS) and Lunar Tithi dates for yearly recurring reminders without annual drift.
  - **Developer CLI Terminal**: Interactive terminal shell with command suggestions (`about`, `skills`, `projects`, `awards`, `contact`, `cv`, `clear`).
- **Complete CV & Information Integration**:
  - TriCalendar project with Java backend details and GitHub link.
  - Live Chat Application with Socket.io.
  - Interactive Art Gallery with Three.js.
  - Winner in Hardware Hackathon (Taranga 2026 @ Dharan ERC) with photo lightbox.
  - Runner Up in Kathford Hackathon with photo lightbox.
  - KEC Software Hackathon 2025 participation.
  - SRDC Research Paper collaboration with college team and faculty.
  - Skills neatly organized into 4 distinct groups: Programming Languages, Web & Full-Stack, Electronics & Embedded Systems, Tools & Design.
  - Direct downloadable CV PDF (`Riman_Maharjan_CV.pdf`).
  - All contact numbers, emails, social links (GitHub, LinkedIn, X, Instagram, Facebook).
